var과 let과 const의 차이

var은 과거에 사용되었던 것으로 안정성이 떨어지고 지역 변수가 함수 내부에서만 인정된다. 또한 변수 호이스팅 동작으로 실행 순서가 상식을 벗어날 수 있다.
let과 const는 안정성이 높으며 차이점은 const는 재할당이 불가능하여 상수를 저장하는데 사용되고 let은 재할당이 가능하며 변수를 저장하는데 사용된다.

js는 호이스팅이 기본적으로 발생하지만 let과 const는 선언만 하고 초기화는 하지 않는다. 

js에서는 숫자 + "숫자"는 문자열로 바뀐다.

여기서 const는 정확히 말하자면 할당된 주소가 고정된다는 것이지 값이 고정된다는 것은 아니다. 그러므로 배열로 선언한 뒤 배열의 값을 바꾸는 것은 허용된다. 하지만 다른 배열로 바꾸는 것은 허용되지 않는다.

let x = true;
let y = x &&= 10;

java와 다르게 js는 논리 할당 연산자가 존재한다. 쉽게 말하면 해당 값이 특정 논리 값이면 특정 값을 대입하는 방식이다.
위에 있는 식은 x가 true면 x에 10을 넣고 다시 x를 y에 대입하므로 y도 10이 된다. 
x &&= 10 으로도 많이 사용한다.

이때 x가 bool값이 아니더라도 논리 할당 연산자는 작동을 한다.
1이나 값이 았는 경우는 true, 0이나 null, undefined의 경우에는 false 취급을 한다. 이때 취급을 한다는 것이지 false 값을 할당받는 것이 아닌 null이나 0 자체를 할당받는다.

||=은 거짓이면 값을 할당하므로 0, null등이면 값이 할당되고 true면 해당 그 값이 할당된다.

??=은 값이 존재하지 않으면 즉, null이나 undefined이면 값이 할당된다.

참고로 빈 배열이나 "0"은 참이다.
